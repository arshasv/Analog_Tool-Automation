================================================================================
SIMPLIFIED API - NEW UNIFIED FLOW
================================================================================

✨ MAJOR CHANGE: Single Unified Endpoint

OLD FLOW (4 requests):
  1. POST /upload → get process_id
  2. GET /parameters/{id} → extract parameters
  3. POST /submit/{id} + params → start execution
  4. GET /status/{id} → get results

NEW FLOW (2 requests):
  1. POST /api/v1/run + file + params → start execution
  2. GET /api/v1/status/{id} → get results

================================================================================
THE SINGLE ENDPOINT
================================================================================

POST /api/v1/run

Request (multipart/form-data):
  • file: Python circuit file
  • parameters: JSON string with values

Example:
  curl -X POST http://localhost:8000/api/v1/run \
    -F "file=@circuit.py" \
    -F 'parameters={"w": 2.0, "l": 0.5, "iref": 10e-6}'

Response:
  {
    "process_id": "proc_a1b2c3d4",
    "filename": "proc_a1b2c3d4_circuit.py",
    "status": "running",
    "parameters": {"w": 2.0, "l": 0.5, "iref": 10e-6},
    "message": "Check status with GET /status/{process_id}"
  }

================================================================================
CHECK STATUS & GET RESULTS
================================================================================

GET /api/v1/status/{process_id}

Example:
  curl http://localhost:8000/api/v1/status/proc_a1b2c3d4

While Running:
  {
    "process_id": "proc_a1b2c3d4",
    "status": "running",
    "progress": 45,
    "parameters": {"w": 2.0, "l": 0.5, "iref": 10e-6},
    "results": null
  }

When Complete:
  {
    "process_id": "proc_a1b2c3d4",
    "status": "completed",
    "progress": 100,
    "parameters": {"w": 2.0, "l": 0.5, "iref": 10e-6},
    "results": {
      "netlist_path": "data/designs/proc_a1b2c3d4.spice",
      "simulation_output": {
        "operating_point": {"vdd": 1.8, "id": 10e-6},
        "ac_analysis": {"gain_db": 42.0, "bandwidth_hz": 900000}
      }
    }
  }
